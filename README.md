# Python-chatbox.py
💬 Basic Chatbot - Python

📌 Project Overview

The Basic Chatbot is a simple rule-based conversational application developed using Python. The chatbot interacts with users by responding to predefined inputs such as greetings, common questions, and exit commands. This project demonstrates the fundamentals of chatbot development and user interaction through a console-based interface.

This project was completed as part of the CodeAlpha Python Programming Internship.

✨ Features

Interactive text-based conversation

Responds to greetings and common questions

Handles user input efficiently

Provides predefined responses

Exit option using the "bye" command

Simple and beginner-friendly implementation
